# AGENTS.md — 当前 Streamlit 页面

## 定位

`src/web/` 是现有 Streamlit 原型和兼容层。它不是未来 React/Next.js 前端，也不是策略引擎。任何新温度计功能应先通过稳定的领域服务或 API 合同提供，不能在页面脚本里重新实现策略。

## 必须遵守

- 读取后端返回的状态、目标权重、版本、更新时间和数据质量；不得硬编码 v10 权重或阈值。
- 页面必须区分 `PROVISIONAL`（盘中观察）和 `CONFIRMED`（收盘确认）。
- 过期、部分、失败和待复核数据必须明显展示，不得用绿色正常状态掩盖。
- “温度”“趋势”“信号一致度”是解释性视图；禁止在页面中写成概率、预测确定性或收益承诺。
- 现有 `Overview`、`Data Management`、`Strategy Backtesting`、`Live Trading`、`Portfolio Analysis`、`Settings` 页面保持兼容，除非用户明确批准迁移。
- `Live Trading` 在当前阶段只能展示纸上交易或禁用状态，不得连接真实下单。
- 视觉参考可以借鉴布局、信息层次和交互习惯，但不得复制第三方代码、品牌、图标、文案或受限素材。

## 修改范围

优先修改组件、页面适配和读取接口；不要在 `app.py` 中堆积数据抓取、指标计算、策略判断或 SQL。需要新后端能力时，先在 `src/api/`、`src/thermometer/` 或 `src/storage/` 定义契约和测试。

每次页面改动至少验证：首次加载、无数据、数据过期、接口错误、不同窗口宽度，以及状态与版本信息是否同时可见。
