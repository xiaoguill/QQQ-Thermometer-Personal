## 差异来源

1. **回放窗口不同。** 旧 v10 报告是研究实验窗口的年度聚合结果；v12.2 当前输出从 2025 年开始，且把每日前缀、预热、信号日和下一交易日执行分别记录。
2. **研究实现与审计实现不同。** 旧 v10 结果来自 recovery overlay 实验分支；v12.2 复用冻结策略链，但新增了每日因果前缀、增量 M03、有限尾部 M04、状态预热、原始快照 hash 链和逐日检查。v12.2 没有为了复制截图而修改策略参数。
3. **价格和执行口径不同。** v12.2 使用本地 QQQ/BIL adjusted close、CBOE VIX/VIX3M，以及独立 VXX 本地缓存；本地 QQQ/VIX 文件只有 close，适配器会重复 close 形成 OHLC，仅用于现有 close 派生指标。旧实验的资产路由和成本分支不能直接视为同一条数据管线。
4. **资产范围不能从服务目录推断为实际持仓。** 旧 v10 数据服务范围包括 QQQ、QLD、VXX、SVXY、BIL、TLT、IAU、XLU、VIX/VIX3M 等；当前冻结的 M07 目标仓位在本次 v12.2 回放中实际使用的是 QQQ、BIL 和冲击状态下的 VXX。其他标的属于数据服务/目录范围，不代表本次策略实际分配了权重。
5. **审计目的不同。** 旧结果主要回答“研究候选在实验窗口表现如何”；v12.2 主要回答“在每一个历史日期只知道当时信息时，温度计和目标仓位是否可复现、是否前视、交易时点是否正确”。因此 v12.2 不应为了追上旧截图收益而回填或调参。

## 使用边界

- 截图结果继续保留，作为旧 v10 研究基线；不删除、不覆盖。
- v12.2 结果作为独立的因果验证产物；它不能证明策略未来会跑赢 QQQ。
- 当前本地数据最新到 2026-08-10，2026 结果是截至该日的部分年度，不是 2026 全年收益。
- VXX 本地缓存是拆股调整 close 代理，不等同于完整总回报序列；VXX 缺失时完整净值回放应 fail-closed。
- 任何后续策略修改必须创建新版本、新配置、新回测目录，并重新进行因果、成本和样本外验收。
