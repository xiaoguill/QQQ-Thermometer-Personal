# M17 纸上调仓计划报告

## 1. 计划的含义

M17 的纸上计划是一个服务器端、只读、可重复的估值预览：

```text
显式本地现金与持仓
        + 最新 Massive 质量为 OK 的观察价格
        + 既有确认 API 的目标权重
        → 当前估值、目标估值和差异值
```

结果会明确返回：

- `paper_only: true`；
- `execution_allowed: false`；
- `order_created: false`；
- 每个标的的 `increase`、`decrease` 或 `hold` 纸上方向；
- 当前数量、当前价值、当前权重、目标权重、目标价值和估算数量差异；
- 价格质量问题和警告。

它不是交易指令，也不是对未来收益的预测。M17 不会提交、确认或写入任何账户。

## 2. 持仓输入

默认文件 `configs/paper/m17.json` 是空输入，页面会显示 `INPUT_REQUIRED`。使用前由用户按真实纸上组合修改本地文件：

```json
{
  "$schema": "qqq-m17-paper-input/v1",
  "portfolio_id": "personal-paper-default",
  "base_currency": "USD",
  "starting_cash": 10000,
  "positions": {
    "QQQ": {"quantity": 10, "average_cost": 400},
    "BIL": {"quantity": 20, "average_cost": 91}
  }
}
```

`average_cost` 只用于页面审计展示，不参与目标差异计算；差异使用当前观察价格估值。禁止把 API key、券商 token、账户号或完整账户导出放进该文件。

## 3. 失败关闭条件

以下任一条件会阻止 `READY` 计划：

1. 没有显式现金或持仓输入；
2. 确认 API 不可用、确认质量不是 `ok` 或目标权重为空；
3. 目标权重无法通过 100% 总和校验；
4. 目标或当前持仓缺少价格；
5. 价格不是 `OK` 或不是盘中临时观察；
6. 组合估值不是正数。

失败时仍返回结构化纸上结果，但 `execution_allowed` 和 `order_created` 始终为 `false`。

## 4. 不过拟合与策略边界

纸上计划不重新实现 v10、M15 或 M16 的指标、阈值、状态机和权重规则。它不根据页面颜色、温度、短期涨跌或用户点击改变策略目标；目标权重只有一个来源，即既有确认 API。这样可以避免前端产生第二套隐含策略，也避免为了当前行情临时调参。

## 5. 适用范围

当前只适合个人本地低频检查。它不提供：

- 券商账户同步；
- 自动调仓或计划执行；
- 订单、撤单、融资、转账或保证金能力；
- 公网服务、多用户权限或生产级高可用。
