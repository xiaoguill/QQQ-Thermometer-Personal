# AGENTS.md — 研究与回测目录

## 适用范围

本规则适用于 `research/qqq_drawdown_strategy/` 及其子目录，并叠加仓库根目录的总规则。本目录是研究实验区，不是自动交易生产区。

## 版本纪律

- 每个新想法必须使用新的实验名、配置快照、输出目录和报告。
- 不覆盖已有 `v*`、`final_*`、`REPORT.md`、CSV、JSON、SQLite 或图表输出。
- 旧的 `final_regime_ensemble` 保留为历史基线；`v10_preserve_shock_recovery` 是当前候选研究版本，两者必须在报告和文件名中明确区分。
- “候选版本”不等于“生产默认版本”。只有完成数据契约、确定性回放、paper shadow 和用户确认后，才可登记为产品默认。
- 不把不同数据源、不同价格口径或不同交易时点的结果拼接成一条净值曲线。

## 当前候选版本的研究约束

v10 的核心不是预测某一天一定暴跌，而是用可复现的冲击入口、恢复解锁和滞回减少长期回撤：

- QQQ 5 日收益不高于 -5%，并且 VIX 水平或 VIX/VIX3M 期限结构满足冲击条件，才允许进入冲击走廊。
- 恢复阶段至少需要两个独立条件确认，例如 QQQ 短期反弹、站上 EMA10、20 日实现波动率下降。
- 中期重新开放风险资产还需要 QQQ 位于 SMA150 之上且 126 日动量为正，并满足连续确认天数。
- 冲击和恢复设置最短持有期；重新冲击必须是新的实际冲击，不因单日 VIX 反复就切换。
- 具体数字只能从冻结配置读取；如果要改数字，创建新版本并说明先验依据、验证区间和未使用区间。

## 回测不可妥协项

- 信号日为收盘后，执行日为下一个交易日；所有 rolling、EMA、RSI、MACD、KDJ、OBV、VIX 结构指标都必须只使用当时可见数据。
- 预热期不得用回测开始日前不可获得的“已知指标”；没有足够历史时按合同定义处理，通常为 BIL/现金或 `WARMUP`。
- 逐年收益、年内最大回撤、全样本最大回撤、回撤持续时间、成本敏感性和与 QQQ 的差异必须同口径计算。
- 至少对 5/10/25 bps 成本做压力测试；如果数据源允许，报告不同供应商或代理数据的差异。
- 不以“80% 年份跑赢”“某年最大回撤更小”作为唯一调参目标；要同时保留未参与选择的验证区间和失败年份。
- 任何策略结果都要附带数据版本、执行规则、成本、再平衡频率、资产上市日期和缺失处理。

## 产物管理

默认新实验输出位置为仓库外的 artifact archive，例如：

```text
D:\Backup\Documents\量化回测\_quant_artifacts\FinRL-Trading\<run_id>\
```

仓库内已有 `output/`、`output_*` 和 `work/` 只作为历史兼容区处理。后续脚本应显式接收 `--output-dir` 或等价参数，不得把新的运行结果静默覆盖到旧目录。

建议每个实验目录至少包含：

```text
experiment_name/
├── README.md              # 假设、版本、不可变规则
├── config.json            # 参数快照
├── data_manifest.json     # 数据源、区间、字段、缺失与抓取时间
├── signals.csv            # 日级状态与指标，不含未来字段
├── weights.csv            # 目标权重与执行日期
├── equity_curve.csv       # 净值、成本、基准
├── annual_metrics.csv     # 逐年结果
├── REPORT.md              # 结论、失败年份、局限与复现命令
└── tests_or_checks.txt    # 运行过的检查
```

实验输出应追加到新目录；如需纠正旧报告，生成 `correction` 或新版本，不删除原始文件。

## 研究与修改流程

1. 先查看 `README.md`、当前实验报告、数据清单和相关测试。
2. 明确本次只验证一个假设，列出不变项。
3. 先写或更新确定性测试，再实现最小改动。
4. 运行局部回放和数据质量检查；不要直接启动会刷新全部历史产物的脚本。
5. 报告基线差异、交易日差异、成本影响和失败案例。
6. 完成当前实验后停止，等待用户批准下一步。

## 研究区禁止事项

- 不在这里放券商密钥、订单函数、定时下单脚本或生产数据库迁移。
- 不用研究结果自动改写 `src/` 下的策略或产品默认配置。
- 不根据最近一年、单次截图或用户账户持仓反推并固化参数。
- 不将 VIX、VXX、SVXY、QLD、BIL、SGOV 当作可互换资产。
- 不因某个指标名称常见就把 EMA、RSI、MACD、KDJ、OBV 全部加入；每个指标必须有预先定义的经济含义和消融测试。
- 不把 `__pycache__`、中间输出和临时工作目录当作研究证据；证据必须由报告、配置、数据清单和 hash 组成。
- 不在 worktree 已经脏的情况下自动刷新全量数据或覆盖历史缓存；先建立 checkpoint 或停下报告。
