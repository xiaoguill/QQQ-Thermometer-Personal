壳层承诺

信息可以被看懂

  • 元数据始终显示时间、确认状态、策略版本和数据质量。
  • 状态同时使用文字、符号和颜色，不依赖单一颜色。
  • 模拟 fixture 有独立 ID，不代表实时数据。

只读 API client

只请求同源 GET

  • 路径来自冻结 OpenAPI 的只读查询端点。
  • 响应内容以安全文本处理，不使用 innerHTML。
  • 没有纸上确认 POST、券商、行情源或远程 API。
