# Northstar 温度计前端 Demo

这是个人版的纯前端概念 demo，使用 HTML/CSS/原生 JavaScript 和模拟数据，不连接后端、行情源或券商，也不修改任何策略规则。

## 运行方式

直接打开 `index.html` 即可；若浏览器限制本地脚本，也可以在本目录启动任意静态文件服务器。

## 设计借鉴边界

- 借鉴 OpenBB 的研究工作台分层、模块化导航和“数据源/证据”意识。
- 借鉴 Grafana 的面板组织、时间范围切换和数据健康状态表达。
- 借鉴 Lightweight Charts 代表的金融图表交互目标，但本 demo 没有复制其代码、组件或品牌资产。
- 借鉴 Streamlit 的快速验证思路，但没有把 demo 绑定到 Streamlit 页面。
- 颜色、文案、品牌名 Northstar、温度计图形和布局均为本项目独立设计。

许可证相关说明见 [docs/FRONTEND_REFERENCE_BOUNDARIES.md](../../docs/FRONTEND_REFERENCE_BOUNDARIES.md)。
